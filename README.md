# windMerchStore

A responsive, dependency-free storefront landing page built with semantic HTML, modern CSS, and a small browser-native JavaScript module.

## What is included

- Responsive navigation with keyboard-operable store and mobile menus
- Product cards rendered from a single data source
- Cart count and accessible status announcements
- Client-side newsletter validation without network submission
- Reduced-motion fallback and visible keyboard focus styles

## Run locally

Open `index.html` in a modern browser. The page uses remote placeholder photography from `picsum.photos`, so an internet connection is needed to load images.

## Project structure

- `index.html` - accessible storefront structure
- `assets/css/style.css` - tokens, responsive layout, interactive states
- `assets/js/app.js` - product data, cart, menus, newsletter behavior
